Privacidade e proteção de dados

Esta página apresenta informações iniciais sobre o tratamento de dados na André Aéreas. O responsável pela operação deve revisar e completar este texto antes de publicar o serviço em produção.

Dados tratados

O sistema pode tratar nome, e-mail, dados de acesso, solicitações de cotação, compras registradas e movimentações do programa de fidelidade. Não solicite nem armazene dados de cartão neste site.

Finalidades

Os dados são usados para administrar contas, responder cotações, registrar compras confirmadas, manter o extrato de milhas e proteger a plataforma.

Direitos do titular

Para solicitar confirmação de tratamento, acesso, correção, informação, eliminação quando aplicável ou demais direitos previstos na LGPD, entre em contato com o responsável pela André Aéreas pelo WhatsApp. Um canal de privacidade dedicado e os prazos de atendimento devem ser definidos pelo responsável.

Retenção e segurança

O sistema usa armazenamento persistente e hashes de senha. A implantação deve usar HTTPS, backups protegidos, controle de acesso e uma política documentada de retenção e exclusão.
